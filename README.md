# Fabricio Santos — QA Engineer / SDET Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript, ready for GitHub Pages.

## Before publishing

1. Verify your name, experience, skills, project descriptions, and links.
2. Confirm that `https://github.com/fabriciosantoss/serverRest` is the correct public repository.
3. Replace the generic experience summaries with verified company names, dates, and achievements.
4. Add a professional contact email. Do not publish confidential client information or private work samples.
5. Check all links and preview the site on desktop and mobile.

## Publish with GitHub Pages

1. Create a GitHub repository named **`fabriciosantoss.github.io`** under your GitHub account.
2. Extract this folder and upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment to finish. Your site should be available at `https://fabriciosantoss.github.io/`.

If your GitHub username differs, use `<your-username>.github.io` as the repository name and update the profile links in `index.html`.

## Local preview

Open `index.html` in a browser. For a closer local development workflow, use VS Code with a local server extension.

## Customization

- Colors and layout: `styles.css`
- Page content and links: `index.html`
- Mobile navigation: `script.js`
